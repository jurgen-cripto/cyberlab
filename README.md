# CYBERLAB — Ethical Hacking Academy

Proyecto educativo local para estudiar fundamentos de Linux, redes, programación y seguridad.

## Estructura

```text
mi-proyecto/
├── servidor.py
├── web/
│   ├── index.html
│   ├── style.css
│   └── script.js
└── README.md
```

## Ejecutar

Desde PowerShell, dentro de `C:\mi-proyecto`:

```powershell
python servidor.py
```

Después abre `http://127.0.0.1:8080`.

### Credenciales demo
- Usuario: `admin`
- Contraseña: `cyberlab`

> El login es solamente una interfaz educativa. No almacena ni protege información real.

## Nota

Los laboratorios deben ejecutarse únicamente en sistemas propios o con autorización.
